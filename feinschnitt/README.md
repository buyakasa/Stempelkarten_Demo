# Salon Feinschnitt – Website + App + Stempelkarte

Eine Web-App: Friseur-Website, Home-Bildschirm-App und digitale Stempelkarte in einem (fiktiver Musterbetrieb).

- Kunden-App: `index.html` (Stempelkarte mit QR-Code, Leistungen und Preise, Terminanfrage, Öffnungszeiten)
- Personal: `mitarbeiter.html` (PIN, QR scannen, +1 Stempel, Prämie einlösen, neue Karte)
- Backend: `backend/` (Google Apps Script, Daten in Google Sheet). Die PIN steht nur in den Skripteigenschaften, nicht hier.
- Einstellungen: `config.js`

Startgrafik selbst gezeichnet, keine Fotos. Terminanfrage ist nur Oberfläche und sendet nichts.
